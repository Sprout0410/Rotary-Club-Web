# 躍齡扶輪社官方網站（第三階段：前台內容全面可編輯）

## 檔案結構
- `*.html`：各頁面（頁首與導覽列由 js/main.js 統一產生，改選單只要改一處 `NAV`）
- `style.css`：全站樣式（第 9 節為第二階段新增）
- `js/main.js`：核心（資料庫、登入、權限、彈窗、圖片壓縮、RC.api 資料介面）
- `js/page-*.js`：各頁專屬功能

## 新頁面
| 頁面 | 用途 | 權限 |
|---|---|---|
| login.html | 登入／申請帳號 | 所有人 |
| admin.html | 審核申請、帳號權限、審核通知寄送、資料備份 | 管理員以上 |
| event-edit.html | 建立／編輯活動（海報、報名表題目、連結相簿） | 管理員以上 |
| event.html?id= | 活動頁、報名名單（姓名遮蔽＋人數）、報名表 | 所有人（名單管理僅管理員） |
| album.html?id= | 相簿瀏覽；上傳／刪除／設封面 | 瀏覽所有人、編輯管理員 |

## 管理員可在前台直接編輯的內容
| 位置 | 編輯方式 |
|---|---|
| 首頁「重大活動展示區」 | 展示區右上角「編輯展示區」：新增／排序／隱藏，照片可上傳、從相簿挑或貼網址，點擊可連到活動頁或外部網址 |
| 首頁活動卡 | 「＋ 建立新活動」 |
| 關於我們 | 創社歷史（文字）、歷屆社長、社友名錄 |
| 最新消息 | 例會時間與地點（與聯絡我們共用）、重大行事曆 |
| 活動與展覽 | 活動、報名名單、相簿 |
| 聯絡我們 | 例會地點、交通與停車指南；地圖依例會地址自動顯示 |

活動若設為「籌備中」並填「報名開始時間」，時間到會自動改為開放報名。

- users → Supabase Auth ＋ profiles 表（role、status），以 RLS 限制管理員權限

- images → Supabase Storage

改接時只需改寫 js/main.js 的「4. 資料庫」與「8. RC.api」，頁面程式不用動。
